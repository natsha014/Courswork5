# 📋 Трекер полезных привычек (DRF + Celery)

## Описание

**Проект представляет собой бэкенд-часть SPA-приложения для отслеживания привычек. Реализована интеграция с Telegram для
рассылки напоминаний и полная автоматизация через Celery Beat**

## Функционал

- **Безопасность:** Настроен CORS.
- **Права доступа:** Разграничение ролей (Неавторизованные vs Создатели).
- **Асинхронность:** Фоновые задачи через Celery (Настроена интеграция с Telegram и рассылки напоминаний).
- **Документация:** Автогенерация Swagger/ReDoc.
- **Пагинация:** Реализована пагинация с выводом по 5 привычек на страницу.

## 🛠 Технологии

- **Python 3.13 + Django + DRF**
- **PostgreSQL** (База данных)
- **Redis** (Брокер сообщений)
- **Celery + Celery Beat** (Отложенные и периодические задачи)
- **Poetry** (Управление зависимостями)
- **Flake8 + Coverage** (Чистота кода и тесты)

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/natsha014/Courswork5
   ```

2. **Настройте переменные окружения:**

   Создайте файл `.env` в корне проекта и заполните его по образцу `.env.sample`
    ```
    SECRET_KEY=
    DEBUG=
    NAME=
    USER=
    PASSWORD=
    HOST=
    PORT=
    CORS_ALLOWED_ORIGINS=
    CSRF_TRUSTED_ORIGINS=
    ALLOWED_HOSTS=
    EMAIL=
    FIRST_NAME=
    LAST_NAME=
    PASSWORD_ADMIN=
    CELERY_BROKER_URL=
    CELERY_RESULT_BACKEND=
    TG_API_KEY=
   ```


3. **Установите зависимости (через Poetry):**
    ```bash
    poetry install

4. **Примените миграции:**
    ```bash
    python manage.py migrate

### ⚙️ Запуск фоновых задач

**Для работы напоминаний необходимо запустить Redis и три процесса Django:**

1. **Сервер API:**
    ```bash
    python manage.py runserver

2. **Celery Worker:**
    ```bash
    celery -A config worker -l info -P solo

3. **Celery Beat (планировщик):**
    ```bash
    celery -A config beat -l info

## Основные эндпоинты

- **habits/** — CRUD привычек пользователя (с пагинацией).
- **habits/public/** — Список всех публичных привычек.
- **users/register/** — Регистрация.
- **users/login/** — Получение JWT-токена.
- **swagger/** — Интерактивная документация API.

## 💡 Особенности реализации

- **Валидаторы:** Реализованы проверки на время выполнения (до 120с), периодичность (не реже раза в неделю) и логику
  вознаграждений.
- **Сигналы:** При любом изменении привычки (через API или Админку) расписание Celery Beat обновляется автоматически
  через Django Signals.
- **Безопасность:** Доступ к привычкам имеет только их владелец (IsOwner).
